## Ricoria Restaurant Website - WordPress

A modern restaurant website built with WordPress, featuring dynamic menu integration with the x2system database.

## 🌐 Live Website:

[View the live website](https://ricoria.pl)

## 📖 About the Project

This project is a website created for a restaurant using WordPress.

One of the main features is the integration with the restaurant's x2system database. The website automatically retrieves menu data from the system and displays it on the website.

This means that restaurant staff can update the menu directly in x2system, and the changes are automatically reflected on the website without having to manually edit the website.

**Key Features:**

🏠 Restaurant website built with WordPress

🍽️ Dynamic menu loaded from x2system

🔄 Automatic synchronization of menu changes

📱 Responsive design for desktop, tablet and mobile devices

🎨 Restaurant-focused visual design

⚡ Simple and convenient menu management

🔗 x2system Integration
<br>
The website communicates with the restaurant's x2system database and retrieves the current menu information.

Workflow:

x2system
    ↓
Database
    ↓
Website integration
    ↓
WordPress
    ↓
Restaurant website
    ↓
Updated menu displayed to customers


Thanks to this integration, the menu displayed on the website stays synchronized with the data maintained in the restaurant management system.

The goal of the project was to create a modern and easy-to-manage restaurant website while eliminating the need to manually update the online menu whenever changes are made in the restaurant's management system.
